A package used to make the `@teams.sdk/apps` package backwards compatible with legacy bots built using
`BotBuilder`.

> ⚠️ **this repository has been moved to https://github.com/microsoft/spark.js** and renamed `@microsoft/spark.botbuilder`.

## Install

```bash
$: npm install @teams.sdk/botbuilder
```

## Dependencies

- [`uuid`](https://www.npmjs.com/package/uuid)
- [`botbuilder-core`](https://www.npmjs.com/package/botbuilder-core)
- [`botframework-connector`](https://www.npmjs.com/package/botframework-connector)
