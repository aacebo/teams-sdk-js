# Activity: Conversation

Teams has several unique conversation update activities that is not found in the original Agents protocol. Those activities are:

- `channelCreated`
- `channelDeleted`
- `channelRenamed`
- `channelRestored`
- `historyDisclosed`
- `membersAdded`
- `membersRemoved`
- `teamArchived`
- `teamDeleted`
- `teamHardDeleted`
- `teamRenamed`
- `teamRestored`
- `teamUnarchived`
- `topicName`
